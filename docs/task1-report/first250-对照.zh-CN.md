# first-250 对照

TencentDB Agent Memory
2026 年 9 月 11 日

`test1k` first-250（250 条 Case）。表体与正式报告 §3.3–3.4 相同。Claude V4 中 76 条含 `.claude/` 的 Case 已用 `quick-08b3193d` 替换。

指标只统计绑定到执行器的 TDAI 请求：失败或选错家族仍计入「发出」；Bash、Read、Grep 等本地命令不计入；TDAI 必要链完成不等于编程任务完成。工具说明长度是首次任务请求中完整工具说明的 `o200k_base` Token，计入共享协议、卡片、指南及绑定后的地址与 header；不计入 Skill 条目正文、用户消息与供应商包装。

## 3. 问题

Claude 全量被 76 条含 `.claude/` 的 Case 拉低。这些 Case 来自 `entireio/cli`、`pc035860/cee`、`melagiri/code-insights`。V4 的不应调用本意是「本轮上下文 / L3 已够用」，不是「git 树里有 Claude 配置」；模型仍把仓库内 `.claude/`、`CLAUDE.md` 当作 TDAI 的替代，该调的不发、不该调的也少不了多少。

baseline 这 76 条中 7 条为 scorable timeout，计入有效样本。下面按是否含 `.claude/` 切开，分母两侧对齐。
